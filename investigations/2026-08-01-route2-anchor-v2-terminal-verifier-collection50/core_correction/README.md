# Route 2 Core correction artifact snapshot

This directory archives the small, reviewable artifacts created for the
2026-08-01 Route 2 correction. It is a provenance snapshot, not an installable
runtime bundle.

## Contents

- `docs/` — architecture contract, full model-consumer audit, migration plan
  and 24+20 protocol;
- `config/` — machine-readable consumer/head contracts, downstream contracts,
  active V1.1 Core policy, Hint shadow policy and sealed cohort lock;
- `reports/` — Core V1 retraining audit and per-model reports;
- `manifests/` — ordered development24, locked-validation20 and cohort
  selection evidence;
- `code/reliability/` — V1.1 Core consumer implementation;
- `code/training/` — feature firewall and frozen CPU training source;
- `code/tools/`, `code/scoring/`, `code/validation/` — cohort builder,
  finalizer, model-input audit, scorers/exporters and validation;
- `code/launch/` — explicit cohort launcher and authorized chain script;
- `code/runtime_candidate/scripts/round_trip_eval.py` — exact corrected
  evaluator snapshot containing the integration wiring;
- `code/tests/` — focused architecture/retraining/wiring tests;
- `run_provenance/` — small immutable launch-time provenance files and the
  completed ep319 downstream/Terminal summaries available at the snapshot.

## Exclusions

The three joblib artifacts and frozen V1.1 portable artifact are identified by
SHA-256 in the reports but omitted. Raw captures, trajectories, logs, videos,
datasets, checkpoints, Python environments and generated bytecode are also
omitted. Absolute paths in reports are historical host provenance, not GitHub
dependencies.

Use `ARTIFACT_MANIFEST.sha256` in the parent investigation to validate this
snapshot.
